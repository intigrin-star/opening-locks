# Мастер замков — Павлодар

Готовый адаптивный сайт на HTML, CSS и JavaScript. Откройте index.html в браузере. Установка и сборка не нужны. Для размещения загрузите index.html, styles.css, script.js и папку assets на статический хостинг, сохранив структуру.

Телефон и WhatsApp: +7 705 611 8006. Номер указан в index.html: tel:+77056118006 и https://wa.me/77056118006. Для замены номера обновите также видимый текст и описание страницы.

Главное фото: assets/master.webp. На телефоне и планшете изображение показано целиком над текстом, с сохранением исходных пропорций, без обрезки и затемнения. На компьютере — справа от текста. Исходный визуальный референс сохранен в assets/reference.png, но не загружается страницей. В исходном фото уже есть надписи; фотография используется без ретуши.

Секции: главный экран, услуги, преимущества, этапы, FAQ, контакты. На мобильных устройствах доступны раскрывающееся меню и закрепленная нижняя панель связи. FAQ работает даже без JavaScript. Внешние шрифты, библиотеки и аналитика не используются. Кнопки открывают приложение телефона или WhatsApp; отправка сообщения остается за посетителем.

Перед публикацией проверьте описание услуг. Фиксированные цены, гарантии, время приезда и круглосуточная работа не указаны, поскольку эти сведения не предоставлены.

Мобильная версия (ширина до 999 px): только шапка без меню, полное фото, строка «ПАВЛОДАР · МАСТЕР НАПРЯМУЮ» и закрепленные снизу кнопки звонка и WhatsApp. Остальные разделы доступны в компьютерной версии.
